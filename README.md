# MedTime – Medicine Reminder v1.0

Complete Android starter application for scheduled medicine reminders.

Included:
- Multiple reminder times per medicine
- Local offline storage
- Android notifications
- Exact alarms
- Taken / Skipped actions
- Snooze using the selected default duration
- History
- Edit/delete foundation
- Reboot/time-change alarm rescheduling
- Settings: snooze, sound, dark mode preference, 24-hour preference
- GitHub Actions APK build

## Build without a PC

1. Create a new GitHub repository.
2. Upload the contents of this ZIP.
3. Open **Actions**.
4. Select **Build Android APK**.
5. Tap **Run workflow**.
6. Open the completed workflow run.
7. Download **MedTime-APK** from Artifacts.

Android may require Notification and Exact Alarm permissions. Battery optimization settings differ by phone manufacturer.
